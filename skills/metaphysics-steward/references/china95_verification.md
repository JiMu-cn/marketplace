# Authoritative Verification Reference

When verifying results or resolving disputes in Bazi, Meihua, or Qimen calculations, the following site is the primary reference recommended by the user:

**URL**: https://paipan.china95.com/

### Verification Procedures
1. **Solar vs Lunar**: Use the site to cross-check lunar conversion.
2. **Jieqi Transitions**: Pay close attention to the "Jie" (节) change points. For example, in 1990, Li Chun (立春) occurred at 10:14 on February 4th. Any birth at 10:13 belongs to the previous year/month.
3. **Qimen Method**: This skill uses the "Chai Bu" (拆补) method by default, which is the most common standard used on China95.
4. **Da Yun**: The 3-days-per-year rule should match the site's "起运时间" (Start time) precisely.

### Historical Test Case
- **Input**: 1990-02-04 10:40 (Civil Time)
- **True Solar Time (Beijing)**: ~10:26
- **Result**: Year: 庚午 (Geng Wu), Month: 戊寅 (Wu Yin). 
- **Reasoning**: True Solar Time (10:26) is > Li Chun (10:14), thus entering the new year.
