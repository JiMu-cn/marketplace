# Bento Grid 布局系统

> 便当网格 = 由内容驱动的灵活卡片布局

## 核心理念

传统 PPT 模板是"先定布局，再填内容"——Bento Grid 则是"先有内容，再选布局"。

```
传统模板思维：这套模板好看 → 把内容硬塞进去
Bento Grid 思维：这些内容重要 → 设计为内容服务
```

## 核心原则

### 1. 灵活性：卡片数量不固定

可以是 1, 2, 3, 4, 5 或更多卡片，取决于如何更好地呈现信息。

### 2. 层级感：尺寸建立层级

使用卡片尺寸建立视觉层级：
- 最重要的信息 → 最大的卡片
- 次要信息 → 中等卡片
- 辅助信息 → 小卡片

### 3. 留白：呼吸感

所有卡片之间保持至少 20px 的间距，让页面有"呼吸感"。

## 画布规格

- **尺寸**：1280 × 720 (16:9)
- **内边距**：40px
- **卡片间距**：20px
- **圆角**：12px（默认）

## 布局类型详解

### 类型 1：单一焦点 (single-focus)

```
┌────────────────────────────────────────────┐
│                                            │
│                                            │
│              大卡片（整页）                 │
│                                            │
│                                            │
└────────────────────────────────────────────┘
```

**适用场景**：
- 封面页
- 单一有力信息（如"我们的使命"）
- 详细图表展示
- 大图配少量文字

**布局参数**：
```javascript
{
  type: 'single-focus',
  cards: [
    { id: 'hero', x: 40, y: 40, w: 1200, h: 640 }
  ]
}
```

---

### 类型 2：两栏对称 (two-col-equal)

```
┌─────────────────────┬─────────────────────┐
│                     │                     │
│                     │                     │
│       左卡片         │       右卡片        │
│                     │                     │
│                     │                     │
└─────────────────────┴─────────────────────┘
```

**适用场景**：
- 两项并列对比（如"旧方案 vs 新方案"）
- 左右分区（文字 + 图片）
- 前后对比

**布局参数**：
```javascript
{
  type: 'two-col-equal',
  cards: [
    { id: 'left', x: 40, y: 40, w: 590, h: 640 },
    { id: 'right', x: 650, y: 40, w: 590, h: 640 }
  ]
}
```

---

### 类型 3：两栏非对称 (two-col-asymmetric)

```
┌───────────────────────────┬──────────────┐
│                           │              │
│                           │              │
│        主内容 (2/3)        │   辅助 (1/3)  │
│                           │              │
│                           │              │
└───────────────────────────┴──────────────┘
```

**适用场景**：
- 主内容 + 侧边栏（如目录、备注）
- 图文混排（文字为主，图片为辅）
- 详细说明 + 关键数据

**布局参数**：
```javascript
{
  type: 'two-col-asymmetric',
  cards: [
    { id: 'main', x: 40, y: 40, w: 780, h: 640 },
    { id: 'sidebar', x: 840, y: 40, w: 400, h: 640 }
  ]
}
```

---

### 类型 4：三栏布局 (three-col)

```
┌───────────┬───────────┬───────────┐
│           │           │           │
│           │           │           │
│   左卡片   │   中卡片   │   右卡片   │
│           │           │           │
│           │           │           │
└───────────┴───────────┴───────────┘
```

**适用场景**：
- 三项并列（如"三大优势"）
- 产品特点对比
- 时间线（过去 - 现在 - 未来）

**布局参数**：
```javascript
{
  type: 'three-col',
  cards: [
    { id: 'left', x: 40, y: 40, w: 386, h: 640 },
    { id: 'center', x: 447, y: 40, w: 386, h: 640 },
    { id: 'right', x: 854, y: 40, w: 386, h: 640 }
  ]
}
```

---

### 类型 5：主次结合 (hero-with-sides)

```
┌─────┬───────────────────────┬─────┐
│     │                       │     │
│     │                       │     │
│ 小  │       主体（居中）      │  小  │
│     │                       │     │
│     │                       │     │
└─────┴───────────────────────┴─────┘
```

**适用场景**：
- 核心概念 + 左右补充
- 人物介绍（头像居中，名字和职位在两侧）
- 主要图表 + 两侧注释

**布局参数**：
```javascript
{
  type: 'hero-with-sides',
  cards: [
    { id: 'left-small', x: 40, y: 200, w: 240, h: 320 },
    { id: 'hero', x: 300, y: 40, w: 680, h: 640 },
    { id: 'right-small', x: 1000, y: 200, w: 240, h: 320 }
  ]
}
```

---

### 类型 6：顶部英雄式 (hero-top)

```
┌────────────────────────────────────────────┐
│                                            │
│              顶部大卡片（英雄区域）          │
│                                            │
└────────────────────────────────────────────┘
┌───────────┬───────────┬───────────┐
│           │           │           │
│   小卡片   │   小卡片   │   小卡片   │
│           │           │           │
└───────────┴───────────┴───────────┘
```

**适用场景**：
- 总结页（总览 + 关键点）
- 产品发布（主图 + 特性列表）
- 项目概览（整体 + 子模块）

**布局参数**：
```javascript
{
  type: 'hero-top',
  cards: [
    { id: 'hero', x: 40, y: 40, w: 1200, h: 300 },
    { id: 'item1', x: 40, y: 360, w: 386, h: 320 },
    { id: 'item2', x: 447, y: 360, w: 386, h: 320 },
    { id: 'item3', x: 854, y: 360, w: 386, h: 320 }
  ]
}
```

---

### 类型 7：混合网格 (mixed-grid)

```
┌─────────┬───────────────────────────┐
│         │                           │
│  中卡片  │          大卡片            │
│         │                           │
├─────────┼───────────────────────────┤
│小 (x2)  │                           │
│         │          大卡片            │
│         │                           │
└─────────┴───────────────────────────┘
```

**适用场景**：
- 复杂内容页面
- 多维度数据展示
- 产品详情（多个特性 + 主图）

**布局参数**：
```javascript
{
  type: 'mixed-grid',
  cards: [
    { id: 'medium', x: 40, y: 40, w: 386, h: 310 },
    { id: 'large-top', x: 447, y: 40, w: 793, h: 310 },
    { id: 'small-1', x: 40, y: 370, w: 190, h: 310 },
    { id: 'small-2', x: 250, y: 370, w: 190, h: 310 },
    { id: 'large-bottom', x: 447, y: 370, w: 793, h: 310 }
  ]
}
```

## 布局选择指南

### 按内容类型选择

| 内容类型 | 推荐布局 |
|---------|---------|
| 封面 / 总结 | single-focus |
| 两项对比 | two-col-equal |
| 图文混排 | two-col-asymmetric |
| 三项并列 | three-col |
| 核心 + 补充 | hero-with-sides |
| 总览 + 要点 | hero-top |
| 复杂多维 | mixed-grid |

### 按信息优先级选择

| 优先级分布 | 推荐布局 |
|------------|---------|
| 1 个核心信息 | single-focus |
| 2 个平等信息 | two-col-equal |
| 1 主 + 1 次 | two-col-asymmetric |
| 3 个平等信息 | three-col |
| 1 主 + 2 补 | hero-with-sides |
| 1 总 + 3 分 | hero-top |
| 多层级混合 | mixed-grid |

## Bento Grid 在策划稿中的使用

策划稿中指定布局时，使用简写格式：

```json
{
  "layout_type": "two-col-asymmetric",
  "layout_config": {
    "main_width_ratio": 0.66,
    "sidebar_width_ratio": 0.34
  }
}
```

设计稿会根据这些配置自动计算具体坐标。

## 响应式调整

Bento Grid 支持根据内容自动调整：

1. **卡片数量调整**：如果内容少，自动合并为更少的卡片
2. **布局降级**：如果三栏内容不合适，自动降级为两栏
3. **内容溢出处理**：如果内容过多，自动拆分到多页

## 设计提示

### 卡片内边距

- 大卡片（整页）：40px
- 中卡片（1/2, 1/3 宽度）：30px
- 小卡片（1/4 宽度）：20px

### 字体大小

- 卡片标题：28px
- 卡片内容：18px
- 辅助说明：14px

### 留白比例

- 页面留白：约 6%
- 卡片间距：约 3%
- 卡片内边距：约 5%
