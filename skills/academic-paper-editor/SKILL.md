# Skill: academic-paper-editor

## 功能描述

专业的学术论文修改助手，帮助研究者改进论文的语言表达、结构逻辑、学术规范。借鉴专业编辑服务的最佳实践，提供具体可操作的修改建议。

## 何时使用

- 完成论文初稿后需要语言润色
- 投稿前需要检查学术规范和格式
- 审稿人反馈语言需要改进
- 需要提升论文的专业性和可读性
- 检查引用格式和参考文献

## 核心修改原则

### 1. 语言正式化（Formal Language）

**有效做法 vs 无效做法：**

| ❌ 避免 | ✅ 使用 |
|--------|--------|
| "a lot of" | "numerous", "substantial", "considerable" |
| "get" | "obtain", "acquire", "receive" |
| "show" | "demonstrate", "indicate", "reveal" |
| "big" | "significant", "substantial", "considerable" |
| "thing" | 具体名词（phenomenon, factor, variable） |
| "good" | "effective", "satisfactory", "favorable" |

**示例：**
- ❌ "We got a lot of data that shows the thing works well."
- ✅ "We obtained substantial data demonstrating that the mechanism operates effectively."

### 2. 消除冗余（Conciseness）

**常见冗余模式：**

| ❌ 冗余表达 | ✅ 简洁表达 |
|------------|------------|
| "due to the fact that" | "because" |
| "in order to" | "to" |
| "at this point in time" | "now" |
| "in the event that" | "if" |
| "for the purpose of" | "for" |
| "it is important to note that" | 直接陈述 |
| "there is/are" 开头 | 使用主动主语 |

**示例：**
- ❌ "There are many researchers who have studied this phenomenon."
- ✅ "Many researchers have studied this phenomenon."

### 3. 客观性（Objectivity）

**避免主观表达：**

| ❌ 主观 | ✅ 客观 |
|--------|--------|
| "I think..." | "The data suggest..." |
| "We believe..." | "The results indicate..." |
| "Obviously..." | "The evidence shows..." |
| "It is clear that..." | 直接陈述事实 |

**例外：** 某些学科（如教育学、人文学科）允许使用第一人称，需根据期刊要求调整。

### 4. 精确性（Precision）

**模糊 vs 精确：**

| ❌ 模糊 | ✅ 精确 |
|--------|--------|
| "some" | 具体数值或比例 |
| "recently" | 具体年份 |
| "many" | 具体数量或"a majority of" |
| "significant"（口语义） | "statistically significant" |

### 5. 连贯性（Coherence）

**段落间过渡：**

| 关系类型 | 过渡词/短语 |
|----------|------------|
| 添加 | furthermore, moreover, additionally |
| 对比 | however, conversely, in contrast |
| 因果 | therefore, consequently, as a result |
| 举例 | for example, specifically, namely |
| 总结 | in summary, collectively, taken together |

## 修改流程

### Step 1: 宏观结构检查

1. **检查论文结构完整性**
   - Abstract：是否包含目的、方法、结果、结论？
   - Introduction：是否清晰阐述研究背景、问题、目的？
   - Methods：是否足够详细以便重复实验？
   - Results：是否客观呈现数据？
   - Discussion：是否解释结果意义、与文献对比？
   - Conclusion：是否总结主要发现、指出局限、展望未来？

2. **检查逻辑流程**
   - 每段是否有明确的主题句？
   - 段落间是否有逻辑过渡？
   - 论证是否从一般到具体？

### Step 2: 段落级修改

1. **主题句检查**
   - 每段开头是否清晰表明该段主旨？
   - 主题句是否过于宽泛或过于狭窄？

2. **支持句检查**
   - 每个支持句是否都与主题句相关？
   - 是否有足够的证据支持论点？

3. **结论句检查**
   - 是否总结该段要点？
   - 是否为下一段做好过渡？

### Step 3: 句子级修改

1. **句子长度检查**
   - 平均长度控制在15-25词
   - 长短句交替，避免单调

2. **主谓一致检查**
   - 确保主语和谓语在数和时态上一致

3. **时态检查**
   - Introduction：一般现在时（普遍事实）、现在完成时（已有研究）
   - Methods：一般过去时
   - Results：一般过去时
   - Discussion：一般现在时（解释意义）、一般过去时（引用本研究）

### Step 4: 词汇级修改

1. **术语一致性**
   - 同一概念是否使用相同术语？
   - 缩写首次出现时是否给出全称？

2. **避免重复**
   - 同一段落内避免重复使用同一词汇
   - 使用同义词或改写句式

3. **拼写检查**
   - 美式/英式拼写统一
   - 专业术语拼写正确

## 引用格式检查

### APA格式要点

1. **文内引用**
   - 一位作者：(Smith, 2020)
   - 两位作者：(Smith & Jones, 2020)
   - 三位及以上：(Smith et al., 2020)
   - 直接引用需加页码：(Smith, 2020, p. 15)

2. **参考文献列表**
   - 按作者姓氏字母顺序排列
   - 悬挂缩进
   - 期刊名斜体，卷号斜体

### 常见引用错误

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| 引用信息不完整 | 确保作者、年份、标题、期刊、卷期、页码齐全 |
| 文内引用与参考文献不匹配 | 双向核对 |
| 二手引用未标注 | 使用"as cited in" |

## 常见错误清单

### 语法错误

1. **冠词使用**
   - 可数名词单数前需加冠词
   - 不可数名词和复数名词表示泛指时不加冠词

2. **单复数一致**
   - "data" 是复数（"datum" 是单数）
   - "phenomenon"（单）vs "phenomena"（复）

3. **介词搭配**
   - "consistent with"（不是"to"）
   - "different from"（不是"than"或"to"）
   - "based on"（不是"in"）

### 学术写作特有错误

1. **过度使用被动语态**
   - 适度使用主动语态增加可读性
   - 方法部分可使用被动语态强调过程

2. **模糊代词指代**
   - 确保"it", "this", "that"指代清晰
   - 必要时重复名词

3. **悬垂修饰语**
   - ❌ "Having completed the experiment, the results were analyzed."
   - ✅ "Having completed the experiment, we analyzed the results."

## 修改示例

### 示例1：Introduction改进

**原文：**
> "In recent years, many researchers have studied machine learning. It is very important. This paper will look at deep learning methods."

**修改后：**
> "Over the past decade, machine learning has emerged as a transformative approach across diverse scientific disciplines (Smith et al., 2018; Jones, 2020). Despite substantial advances in algorithm development, the application of deep learning methods to [specific domain] remains underexplored. The present study addresses this gap by..."

**改进点：**
- 具体化时间范围（"Over the past decade"）
- 添加文献引用
- 明确研究空白
- 使用正式表达（"emerged as", "underexplored"）

### 示例2：Methods改进

**原文：**
> "We used some software to analyze the data. The parameters were set as default."

**修改后：**
> "Statistical analyses were performed using R version 4.0.3 (R Core Team, 2020). All parameters followed software defaults unless otherwise specified: α = 0.05 for significance testing, and missing data were handled using listwise deletion."

**改进点：**
- 指定软件名称和版本
- 说明具体参数设置
- 提供可重复的细节

### 示例3：Results改进

**原文：**
> "The results were very significant. Group A did much better than Group B."

**修改后：**
> "Group A demonstrated significantly higher performance compared to Group B (M = 85.3, SD = 4.2 vs. M = 72.1, SD = 5.8), t(58) = 10.24, p < 0.001, d = 2.68."

**改进点：**
- 提供具体统计值
- 报告效应量
- 使用精确的统计语言

## 使用示例

**用户：** "请帮我修改这段Introduction"

**助手：**
1. 分析原文的问题（语言、结构、逻辑）
2. 按照修改原则逐句改进
3. 解释每处修改的原因
4. 提供修改后的完整版本
5. 给出通用改进建议

## 注意事项

1. **尊重作者原意**：修改时保持原意不变，只改进表达方式
2. **学科差异**：不同学科有不同的写作惯例，需灵活调整
3. **期刊要求**：遵循目标期刊的具体格式要求
4. **适度修改**：避免过度编辑，保持作者的个人风格
5. **解释清楚**：每次修改都要说明原因，帮助作者学习
